Exetat: DRC National Exam Results Analysis

Personal project · Data engineering & analytics

Exetat-analysis is an end-to-end data platform that makes results from the Democratic Republic of the Congo's National State Examination (Examen d'État) easier to access and analyse.

The problem

Data transparancy ,Official results were published as government PDF reports, which are hard to search, compare or analyse.

The approach

Extract the tables from the PDFs using Python regular expression and pdf plumber, organise them in a relational MySQL database, and present them through an interactive analytics dashboard using dash and plotly..

tools & libraries used .

Python, Mysql, SQL , Json, pdfplumber, Regex, Plotly and Dash , panda.
